# Frontend Design

This portfolio website is designed as a refined frontend experience built with Next.js, TypeScript, and Tailwind CSS. It focuses on clarity, responsiveness, and modern UI patterns to showcase the content and core skills effectively.

## Design Goals

- **Clean presentation**: Minimal visual noise with sharp typography and spacing.
- **Responsive layout**: Works seamlessly on mobile, tablet, and desktop.
- **Dark mode support**: Smoothly toggles between light and dark themes.
- **Fast load times**: Optimized assets and static rendering where possible.
- **Accessible interactions**: Focus states, readable contrast, and keyboard navigation.

## Key UI Elements

- **Navigation**: Simple top navigation with clear page sections and mobile-friendly behavior.
- **Hero section**: Strong introduction with headline, summary, and call-to-action.
- **About section**: Professional overview and personal highlights.
- **Projects grid**: Visual project cards with concise descriptions and links.
- **Resume section**: Downloadable resume and career overview.
- **Contact form**: Interactive form with email integration for easy outreach.

## Technology Stack

- **Next.js**: Framework for React-based frontend rendering and routing.
- **TypeScript**: Type safety for components and app logic.
- **Tailwind CSS**: Utility-first styling for consistent component design.
- **Lucide React**: Icon set for visual clarity and branding.

## Visual Style

- **Color palette**: Neutral background tones balanced with accent colors.
- **Typography**: Modern sans-serif fonts with strong hierarchy.
- **Spacing**: Consistent padding and margin for clean structure.
- **Transitions**: Subtle hover and theme transitions for polished interaction.

## User Experience

- Loads quickly on initial render.
- Keeps navigation intuitive and minimal.
- Maintains consistent design across all pages.
- Supports user preference for theme with persistence.
